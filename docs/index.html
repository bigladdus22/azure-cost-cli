Azure Cost Estimator

Price an application's Azure footprint from prices cached in your Supabase project. A server-side function keeps the cache fresh from the public Azure Retail Prices API; the page only ever reads from Supabase — fast, and no cross-origin calls to Microsoft.

Supabase connection

Stored in this browser only (localStorage). The anon key is safe to expose — the azure_prices table is read-only under row-level security. Not set up yet? See the refresher's README.

Settings

Currency and region must be present in the cache — refresh the function with a matching AZURE_PRICE_CURRENCY / filter if a lookup finds nothing.

Resources

Label Azure service Region ARM SKU (optional) Price type Qty / month

Quantity is billed units per month — e.g. 730 hours for an always-on VM, or GB-months of storage. Add an ARM SKU (like Standard_D2s_v5) to pin an exact meter.

Load inventory from Supabase (optional)

Reads the applications / application_resources tables with the same anon key (needs an RLS SELECT policy on them). Writing cost snapshots stays with the CLI — it needs the secret key.
